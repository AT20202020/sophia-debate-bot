# Historicity argument cards

Each `.md` file in this folder is one argument about whether Jesus existed.
Sophia gets only the card(s) that match what's being argued, not the whole folder.

## Rules for every card

1. **Both sides at full strength.** Each card gives the best version of the case
   for AND against. If a reader can tell which side the writer is on, rewrite it.
2. **No verdicts.** Cards describe evidence and who argues what. They never tell
   Sophia what to conclude.
3. **Attribute everything.** "Carrier argues...", "Ehrman argues...". Never
   "scholars agree" without saying which ones and how many.
4. **Your own words.** Summarize books, don't paste them. Short quotes of ancient
   sources (a Bible verse, a line of Josephus) are fine.
5. **Keep it short.** Aim for about 2,000 characters of body text or less. A card gets
   added to her context while she's talking, so length costs speed.

## Template

Copy `_TEMPLATE.md`, rename it (lowercase-with-dashes.md), fill it in.
The `triggers:` line lists words or phrases that should pull this card in
(case doesn't matter, separate with commas). Include common Whisper
mishearings if you know them.

Files starting with `_` are ignored by Sophia.
